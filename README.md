🐱 Cat Breed Descriptions Fetcher
This simple JavaScript app fetches cat breed information from TheCatAPI and displays a clean list of breed names with their descriptions.

🚀 Features
Fetches all cat breeds using fetch and TheCatAPI.

Displays breed name + detailed description.

Easy to run in Node.js or browser console.


📦 Usage
Clone the repo or copy the script.

Run it in any JavaScript environment (e.g., browser console or Node.js).

Outputs each breed's name followed by a short description.
